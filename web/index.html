The Problem

Why autonomous agents break down after 30 turns

As multi-turn dialogues grow, language models struggle with state conflict, payload bloat, attention loss, and provider cache eviction.

01 • State Conflict

Contradiction & Ghost State

High Severity

A user updates their delivery address or flight date 15 turns in. Later, when executing an action, the LLM hallucinates between both values in context or silently executes against the obsolete state.

Transcript Drift Trace State Collision 
# Turn 3: User sets initial invariant
> user: Book flight to "SFO" on Oct 12.
# Turn 18: User updates their constraint
> user: Actually change that to "JFK" instead.
# Turn 28: LLM sees both turns, resurrects stale state
! error: Agent executed action with destination="SFO"
Failure rate: 42% of multi-turn tool errors
02 • Token Inflation

Tool Payload Bloat & Token Bleed

Token Inflation

Bash command runs, SQL tables, and vector lookups dump hundreds of lines of raw tabular noise that no future turn ever reads again. Token bills explode, latency spikes, and attention evaporates.

03 • Attention Loss

Lost-in-the-Middle Decay

Attention Loss

Critical user constraints and business invariants placed in the middle of a 40+ turn transcript suffer from U-shaped attention degradation. The LLM quietly ignores constraints without throwing an error.

04 • KV Eviction

Prompt Cache Thrashing

0% KV Hit Rate

Naive pruning or sliding-window truncation mutates early message boundaries on every turn. This breaks byte-identical prefixes, invalidating provider KV caches and driving TTFT to multi-second delays.

> prefix: Byte-exact prefix stream mutated

> latency: TTFT spikes from 85ms to 2,420ms

The Architecture

The 4-stage context compilation pipeline

Each step is a pure, total mathematical function over the transcript. Zero model in the loop, zero stochastic drift, and identical input always yields identical output.

PIPELINE ACTIVE ContextGC · DAG Orchestrator
4 Stages Active 3 Transforms PURE DAG

Drag stages to re-route · Cubic Bézier connectors update dynamically

Capabilities

Engineered for safety, speed, and determinism

Everything required to operate production AI agents reliably across hundreds of turns.

DAG Engine 01

Deterministic State DAG

Mathematical tracking of entity lifecycles. When a key is re-asserted, the prior turn is retired; when a key is voided, it is cleanly struck from active state.

Safety Gate 02

Safety-First Compactor

Compresses multi-row tool payloads by up to 80% while guaranteeing that any row carrying allergen, PII, security, or expiry signals is strictly preserved.

Cache Align 03

KV-Cache Prefix Preserver

In cache_friendly mode, unchanged prefix messages are emitted byte-identical, retaining provider KV cache hits across model generations.

Dual Path I/O 04

Dual Read & Write Path

Extracts implicit facts using measured regex schemas on the read path, or receives direct declarations from the agent via <contextgc-state> blocks.

Evidence Gate 05

Lexical Evidence Gate

A turn is never retired if it remains the sole supporting evidence for an active fact. Orphaned assertions are mathematically prevented.

Pure Python 06

Zero-Dependency Core

Written in 100% pure standard-library Python (3.9–3.13). Installs instantly, needs no PyTorch or heavy NLP dependencies, and compiles in <3ms.
