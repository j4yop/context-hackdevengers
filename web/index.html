The Problem

Why autonomous agents break down after 30 turns

As multi-turn dialogues grow, language models struggle with state conflict, payload bloat, and lost-in-the-middle context drift.

⚠

1. Contradiction & Ghost State

A user changes their delivery address or flight date 15 turns in. Later, when executing an action, the model sees both values in context and flips between them or hallucinates a blend.

High Severity
📦

2. Irrelevance & Token Bleed

Bash tool runs and SQL lookups dump hundreds of lines of raw tabular data that no turn will ever read again. Token bills explode, latency spikes, and attention span evaporates.

Token Inflation
🕒

3. Attention Position Decay

Important user constraints placed in the middle of a 50-turn dialogue suffer from lost-in-the-middle decay. Critical invariants are quietly ignored by the model.

Attention Loss
The Architecture

The 4-stage context compilation pipeline

Each step is a pure, total mathematical function over the transcript. Zero model in the loop, zero stochastic drift, and identical input always yields identical output.

01

Ingest & Normalize

Parses OpenAI, Anthropic, or raw text transcripts into normalized turn records with role signatures, tool IDs, and payload boundaries.

02

State DAG Construction

Constructs an Entity State DAG tracking entity lifetimes, confidence, Last-Write-Wins timestamps, and provenance (declared vs inferred).

03

Retire & Compact

Retires turns whose facts are completely superseded. Compactor samples bulk rows while strictly protecting safety flags (allergens, PII, expiry).

04

Assemble & Cache Align

Injects the authoritative [ACTIVE_AGENT_STATE] register and formats messages with byte-identical prefixes for maximal KV cache hit rates.

Capabilities

Engineered for safety, speed, and determinism

Everything required to operate production AI agents reliably across hundreds of turns.

⚙

Deterministic State DAG

Mathematical tracking of entity lifecycles. When a key is re-asserted, the prior turn is retired; when a key is voided, it is cleanly struck from active state.

🛡

Safety-First Compactor

Compresses multi-row tool payloads by up to 80% while guaranteeing that any row carrying allergen, PII, security, or expiry signals is strictly preserved.

⚡

KV-Cache Prefix Preserver

In cache_friendly mode, unchanged prefix messages are emitted byte-identical, retaining provider KV cache hits across model generations.

✏

Dual Read & Write Path

Extracts implicit facts using measured regex schemas on the read path, or receives direct declarations from the agent via <contextgc-state> blocks.

🔗

Lexical Evidence Gate

A turn is never retired if it remains the sole supporting evidence for an active fact. Orphaned assertions are mathematically prevented.

🚀

Zero-Dependency Core

Written in 100% pure standard-library Python (3.9–3.13). Installs instantly, needs no PyTorch or heavy NLP dependencies, and compiles in <3ms.

Engineering Rigor

What it does not do

The failure modes are documented because you will hit them, and a tool that only lists its strengths is not one you can rely on.

  • It does not make models reliable. It removes contradictions from the input. It cannot add judgement, and it will not stop a model ignoring a rule you pinned.
  • Read-path state tracking is regular expressions. There is no coreference resolution, so a fact expressed only through pronouns will not be tracked. Missed extraction is the main failure mode: the state is silently incomplete rather than loudly wrong. Extend it with StateDAG.register_entity_schema().
  • The write path is unproven, not working. On 6 real trajectories a 14B model names a schema slot 96% of the time and emits well-formed JSON every turn — and every resulting addition is still a value of the wrong shape: three literal Nones, and error messages where a test identifier belongs. Checking the key is not checking the value — so a schema may now state a value contract per slot, which drops 24 of the 55 declarations in that capture. It removes an invisible failure; it does not prove the rest.
  • Token counts are chars/4, not a BPE tokenizer. Read them as a ratio, not a bill. Exact figures need tiktoken against your model.
  • Retired-turn recall is lexical — token, subword and phrase overlap, not semantics. “What did we decide about billing?” will not find a turn that only says “invoice”.

Quick Start Integration
from contextgc import compile_transcript

# Compile any multi-turn conversational transcript
result = compile_transcript(
    transcript=raw_messages,
    entity_schema="travel",       # or "coding", "logistics"
    mode="cache_friendly",        # preserves byte-identical KV prefix
    invariants=["refunds over 500 require human manager approval"]
)

# Pass the compiled context directly to your model
response = client.chat.completions.create(
    model="gpt-4o",
    messages=result.compiled_messages
)

print(f"Reduced context by {result.telemetry.compression_ratio_pct}% in {result.telemetry.compile_time_ms}ms")
